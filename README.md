## 📌 專案簡介

為台大學生設計的「個人美食地圖與飲食紀錄」系統：
- 整理餐廳分類（依照個人的喜愛、想嘗試、別人推薦等分類）
- 記錄台大校內餐廳資訊
- 查看用餐紀錄(美食日曆)
---
